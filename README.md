Salary & Compensation Analysis

Overview
This project explores employee salary and compensation data to identify differences across departments, education levels, and years of experience.

Objectives
- Compare average base salaries across departments.
- Analyze employee counts and average bonuses by department.
- Explore the relationship between experience and compensation.
- Identify data-quality issues that may affect the results.

Tools Used
- Excel: Data cleaning, Power Query, PivotTables, and charts.
- SQL (SQLite): Filtering, sorting, aggregation, grouping, and joining tables.
- Power BI: Salary analysis dashboard and data visualization.

Data Quality
- Potential issues identified include missing experience values, unusual salary values, unknown education categories, and inconsistencies in total compensation calculations.

- Questionable records were flagged for review rather than automatically corrected.

 Project Files
- Project files will be added to this repository as they are prepared for sharing.

Limitations
- Salary averages may be affected by outliers, missing values, and unresolved data inconsistencies. Results should be interpreted with these limitations in mind.
